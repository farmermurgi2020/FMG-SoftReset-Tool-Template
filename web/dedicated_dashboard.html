FMG Soft Reset Tool — Dedicated

Local settings page. Settings are saved to this PC and can be synced to a private GitHub repository. SFTP secrets are sent encrypted to GitHub and are never written to the local settings file.

GitHub destination

For Sync and Run dry-run, create a fine-grained token limited to this private repository with Contents, Workflows, Actions, and Secrets write permissions. The page keeps it in memory only. Never paste it into chat or a config file.

Pine Hosting SFTP and save paths

SFTP credentials (optional on later syncs)

Use the Pine Hosting SFTP password, or a private key if SSH key login is configured. The private key and passphrase are optional. The known_hosts line is also optional: if supplied, the worker verifies the server against it; if blank, it accepts an unpinned host key. Blank fields keep previously saved GitHub secrets unchanged.

Reset and schedule

For each kind of data, choose what a reset does. "Keep protected zones" keeps whatever overlaps your protected zones and safehouses (8×8-tile map chunks; 256×256-tile population cells). "Reset everything" ignores the zones for that kind of data. "Don't touch" leaves it as it is.

zpop_ids.bin and zpop_virtual.bin are always kept because they cannot be split by location.

The worker does not check whether the server is running. Scheduled apply relies on your Pine Hosting power schedule stopping the server before the reset time and starting it after the window. Keep scheduled runs on dry run until a manual apply and rollback have been tested.

Reset now / roll back

Stop the server in the Pine Hosting panel first and wait until it shows offline. Apply resets every unprotected map chunk; the original map is kept in a single softreset.rollback-… folder in the save (older ones are deleted). Rollback swaps that folder back in, and the replaced state becomes the new rollback folder, so a rollback can itself be undone.
